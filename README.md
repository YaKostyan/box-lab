# ToffiPacks — сайт і backend замовлень

Адаптивний сайт для підбору коробок за внутрішніми розмірами, розрахунку ціни та оформлення однієї заявки з кількома позиціями. Підбір ураховує поворот предмета, запас із кожного боку, зберігає останні розміри та чесно позначає найближчі, але замалі варіанти. На головній також є блоки про ToffiPacks, сертифіковану вторинну сировину, роботу з бізнесом, переваги, доставку й оплату.

## Відкрити без встановлення

Відкрийте подвійним кліком `TOFFIPACKS-OPEN-ME.html`. Це автономна версія: інтернет, Node.js і локальний сервер не потрібні.

## Запуск проєкту

Потрібні Node.js 24+ і pnpm.

```bash
pnpm install
pnpm dev
```

Production-перевірка frontend і backend:

```bash
pnpm test
pnpm check
pnpm build
```

## Backend

Повноцінний сервер розташований у `server/`: Node.js 24, SQLite, безпечні сесії, акаунти за телефоном, спільні товари/клієнти/заявки, серверний розрахунок ціни, ролі, аудит і необов’язкові Telegram-повідомлення.

```bash
copy server\.env.example server\.env
node --env-file=server/.env server/index.mjs
```

Після цього в кореневому `.env` задайте `VITE_API_BASE_URL=http://localhost:8787` і запустіть `pnpm dev`. Повна інструкція та Docker-запуск — у `docs/PRODUCTION-BACKEND.md`.

## Де змінювати дані

- `src/data.ts` — початкові 12 товарів, розміри, базові ціни, правила розрахунку та відповіді FAQ.
- `src/main.ts` — тексти головної, каталог, картка коробки, калькулятор, кошик, заявки, кабінет і сторінка менеджера.
- `src/styles.css` — палітра ToffiPacks, компоненти, адаптивність і анімації.
- `public/toffipacks-logo.webp` — оптимізована копія наданого логотипа.
- `server/` — API, SQLite-схема, авторизація, серверні правила ціни та інтеграційні тести.
- `docs/PRODUCTION-BACKEND.md` — запуск, маршрути, Docker і підключення GitHub Pages до API.

## Ціни

Клієнтський інтерфейс показує тільки кінцеву ціну за одиницю та весь тираж. Внутрішні правила розрахунку зберігаються у `src/data.ts`. Для підтверджених постійних клієнтів автоматично застосовується персональна ціна.

Кошик зберігається у браузері та підтримує кілька різних розмірів з окремою кількістю кожного. Кількість можна змінювати кнопками або вручну, а зареєстрований клієнт може повторити попередню заявку.

## Сторінка менеджера

Після входу відкриваються окремі розділи: огляд, замовлення, клієнти й товари. Замовлення можна шукати, фільтрувати за одним днем або періодом у власному календарі: перший клік задає початкову дату, другий — кінцеву. Також заявки можна переводити між статусами, видаляти та переглядати історію змін. На огляді можна завантажити серверну резервну копію. У розділі «Товари» можна створювати й редагувати коробки, змінювати розміри та базову ціну, приховувати позиції з сайту, видаляти їх, а також імпортувати й експортувати CSV. Коли API підключено, зміни одразу зберігаються у спільній SQLite-базі та записуються в журнал аудиту.

Онлайн-версія реєструє service worker і кешує основну оболонку для повторного відкриття без стабільного з’єднання. Автономний `TOFFIPACKS-OPEN-ME.html` працює окремо без service worker.

## Тестові акаунти автономного демо

- Адмін: `+380000000001` / `admin123`
- Постійний клієнт: `+380671112233` / `client123`

Backend при першому запуску створює тільки адміністратора з `ADMIN_PHONE` та `ADMIN_PASSWORD`; клієнти реєструються через сайт. У production стандартний пароль заборонений.

## Режими роботи

Акаунти ідентифікуються номером телефону; email не використовується. Якщо `VITE_API_BASE_URL` задано, сайт використовує серверну базу, захищену авторизацію та спільні дані на різних пристроях. Якщо адреса API порожня, GitHub Pages та автономний HTML залишаються у демо-режимі з `localStorage`.

Для реального запуску треба розмістити Docker-контейнер backend на сервері з постійним диском, задати надійний пароль адміністратора та HTTPS-адресу API. Контакти, умови доставки й оплати та правила персональних цін усе ще мають бути підтверджені власником.
