# ToffiPacks — інтерактивний прототип

Адаптивний сайт для підбору коробок за внутрішніми розмірами, розрахунку ціни та оформлення однієї заявки з кількома позиціями. На головній також є блоки про ToffiPacks, сертифіковану вторинну сировину, роботу з бізнесом, переваги, доставку й оплату.

## Відкрити без встановлення

Відкрийте подвійним кліком `TOFFIPACKS-OPEN-ME.html`. Це автономна версія: інтернет, Node.js і локальний сервер не потрібні.

## Запуск проєкту

Потрібен Node.js 20+.

```bash
npm install
npm run dev
```

Production-перевірка:

```bash
npm run check
npm run build
```

## Де змінювати дані

- `src/data.ts` — 12 товарів, розміри, базові ціни, правила розрахунку та відповіді FAQ.
- `src/main.ts` — тексти головної, каталог, картка коробки, калькулятор, кошик, заявки, кабінет і сторінка менеджера.
- `src/styles.css` — палітра ToffiPacks, компоненти, адаптивність і анімації.
- `public/toffipacks-logo.webp` — оптимізована копія наданого логотипа.

## Ціни

Клієнтський інтерфейс показує тільки кінцеву ціну за одиницю та весь тираж. Внутрішні правила розрахунку зберігаються у `src/data.ts`. Для підтверджених постійних клієнтів автоматично застосовується персональна ціна.

Кошик зберігається у браузері та підтримує кілька різних розмірів з окремою кількістю кожного.

## Важливе обмеження

Акаунти ідентифікуються номером телефону; email не використовується. У поточній статичній версії акаунти, кошик і заявки зберігаються у `localStorage` браузера. Для роботи між різними пристроями потрібні backend, база даних, SMS-авторизація та серверний хостинг.

Перед запуском треба підтвердити контакти, умови доставки й оплати та правила персональних цін.
