# Box Lab — інтерактивний прототип

Адаптивний демо-сайт для підбору коробки за предметом і внутрішніми розмірами. Концепція: **A — Box Lab**. Усі ціни, товари, строки та наявність навмисно позначені як демонстраційні.

## Відкрити без встановлення

Просто двічі клацніть `BOX-LAB-OPEN-ME.html`. Це автономна версія: Node.js, Vite, сервер та інтернет не потрібні.

## Запуск

Потрібен Node.js 20+.

```bash
npm install
npm run dev
```

Vite покаже локальну адресу, зазвичай `http://localhost:5173`.

Перевірка й production-збірка:

```bash
npm run check
npm run build
npm run preview
```

## Де що змінювати

- `src/data.ts` — 8 демо-товарів, призначення, FAQ, дисконтні правила й дисклеймер.
- `src/main.ts` — структура секцій, SVG-схеми, каталог, картка товару, конструктор і форми.
- `src/styles.css` — дизайн-система, сітка, адаптивність, focus/hover/loading/error/success.

## Демо-механіки

- Підбір у першому екрані фільтрує каталог за внутрішніми розмірами; предмет можна повертати всередині коробки.
- Пошук, призначення, тип, матеріал, наявність, брендування, поштова придатність і сортування працюють локально.
- Ціна за штуку: 50+ −10%, 100+ −18%, 500+ −28%; це демонстраційне правило.
- Картка товару відкривається як доступний діалог; кількість і логотип перераховують суму.
- Конструктор зберігає введення між кроками й може записати результат у `localStorage` під ключем `box-lab-calculation`.
- Форма нічого не надсилає. Значення `error` у полі контакту демонструє стан помилки; звичайні валідні дані — стан успіху.
- Пошук `помилка` демонструє помилку каталогу; несумісні фільтри — порожню видачу.

## Потрібні реальні дані

Перед запуском власник має надати назву й логотип, фактичний каталог і конструкції, внутрішні/зовнішні розміри, матеріали та щільності, ціни за тиражами, мінімальні партії, наявність, строки, умови брендування, доставку, оплату, повернення, контакти й місто виробництва.
