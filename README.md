# ToffiPacks — інтерактивний прототип

Адаптивний сайт для підбору коробок за внутрішніми розмірами, розрахунку ціни тиражу та збереження заявок. Каталог і базові ціни перенесені з `Price_List_ToffiPacks-v3.xlsx`.

## Відкрити без встановлення

Відкрийте подвійним кліком `TOFFIPACKS-OPEN-ME.html`. Це автономна версія: інтернет, Node.js і локальний сервер не потрібні.

## Запуск проєкту

Потрібен Node.js 20+.

```bash
npm install
npm run dev
```

Production-перевірка:

```bash
npm run check
npm run build
```

## Де змінювати дані

- `src/data.ts` — 12 товарів, розміри, базові ціни, матеріал, правила ціни та FAQ.
- `src/main.ts` — каталог, модальна картка коробки, калькулятор, заявки, кабінет за телефоном і демо-адмінка.
- `src/styles.css` — палітра ToffiPacks, компоненти, адаптивність і анімації.
- `public/toffipacks-logo.webp` — оптимізована копія наданого логотипа.

## Правила ціни у прототипі

- 1–999 шт.: базова ціна з прайсу + 2 грн за штуку.
- 1000–50 000 шт.: базова ціна з прайсу + 1 грн за штуку.
- Для підтверджених постійних клієнтів адмін задає індивідуальну націнку, нижчу за публічну.
- Матеріал у каталозі один: мікрогофрокартон, крафт.

Наприклад, коробка №101 має базову ціну 4 грн, роздрібну 6 грн і оптову 5 грн.

## Важливе обмеження

Це чесний клієнський прототип. Акаунти ідентифікуються номером телефону; email не використовується. Індивідуальні ціни й заявки зберігаються тільки у `localStorage` поточного браузера. Щоб заявки з телефонними номерами надходили власнику, а клієнти входили з різних пристроїв, потрібні реальний backend, база даних, SMS-авторизація та хостинг серверної частини.

Перед запуском також треба підтвердити значення безіменної помаранчевої колонки у прайсі, точну назву матеріалу, контакти, умови доставки й оплати та правила індивідуальних цін.
